## 生成器健壮性修复清单（bash/gen-contract.py）

- 递归返回类型剥壳：`YdszResponse<PageResponse<X>>` 正确产出 `PageResponse<X[]>`（修复裸 `PageResponse`）
- Java 枚举提取：仅取大写常量标识符，忽略构造参数（修复 `defaultSeverity?: 'INFO' | '1' | ...` 垃圾值）
- JS 保留字函数名：`delete` → `deleteApi`
- 空类型引用时移除 import 行（修复 `import type { Record<string, never> }`）
- `@ydsz/tsconfig` 类路径占位符（`${prop:/default}`）替换为默认值（修复 SCIM 路径损坏）
- `api/index.ts` 仅保留 `core` + `models` 导出（避免多 Controller 重名函数 `get/stats/validate` 触发 TS2308）
- 枚举字符串字面量不误导入（`'RECEIVED'` 等不作为类型名）
- `JavaSource` 负缓存 + 搜索范围收窄 `[服务, common]`（解析性能提升一个数量级，userinfo 从超时→秒级）
- models.ts 在 API 文件生成后写入（修复 `RuleDefinitionVO` 等类型缺失）
