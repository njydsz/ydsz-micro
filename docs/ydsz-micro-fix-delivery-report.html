一、P0 批次（5/5 完成）

P0已修复P0-2 修复 command-palette.vue 事件注销 Bug

原 onUnmounted 中 removeEventListener 传入新空函数引用导致监听器无法移除（内存泄漏）。已提取具名处理函数 handleRegisterCommands / handleUnregisterCommands 并正确注册/注销。同时清理未使用的 getPreloadManager import。

P0已修复P0-3 拆分 bootstrap.ts（406 行 → 18 项职责解耦）

  • main/src/setup/monitoring.ts — 监控 / Canary / DevTools / 会话同步

同时将 microRuntime 改为 export let（ESM import 绑定对外只读，实现"可读不可改"），外部 3 处引用（subapp/index.vue、use-tabbar-micro-sync.ts、devtools-bridge）无需改动。

P0已修复P0-4 notificationStore 迁移到 Pinia

store/notification.ts 从 class-based singleton 迁移为 defineStore('notification', () => {...}) setup store，获得 DevTools 调试、$reset 等能力。layouts/basic.vue 改用 useNotificationStore()，.value 访问随 Pinia 自动解包调整。
