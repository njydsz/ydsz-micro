# 组件总览

YDSZ-UI 当前版本提供 **90+** 组件，按功能域分类组织。每个组件都经过无障碍测试验证，并支持明暗双主题。

## 基础组件

| 组件 | 说明 | 文档链接 |
|------|------|---------|
| Button | 支持多种变体、尺寸与加载状态的按钮 | [Button](/components/button) |
| Input | 单行文本输入框，支持 v-model | [Input](/components/input) |
| Select | 选择器，基于 Radix Vue Select | [Select](/components/select) |
| Table | 数据表格，支持排序/固定列/虚拟滚动 | [Table](/components/table) |
