## 三、use-resize.ts 文件拆分详情（P1-2）

### 原始文件
- `use-resize.ts`：810 行（超规范 500 行上限 62%）

### 拆分后结构

| 文件 | 行数 | 职责 |
|------|------|------|
| `use-resize-types.ts` | ~60 行 | 类型声明（纯类型文件，适用声明豁免） |
| `use-resize-style.ts` | ~30 行 | 样式映射常量 |
| `use-resize-utils.ts` | ~100 行 | 计算工具函数 |
| `use-resize-core.ts` | 534 行 | 核心拖拽/调整逻辑（calcDragLimitation/calcResizeLimits/stickMove/bodyMove 等） |
| `use-resize-events.ts` | 292 行 | 事件处理函数（stickDown/move/up/bodyDown + addEvents/removeEvents） |
| `use-resize.ts` | 53 行 | 重新导出入口（向后兼容） |

### 循环依赖处理

采用单向依赖链：
```
use-resize.ts (入口)
  ├── use-resize-types.ts (纯类型)
  ├── use-resize-style.ts (常量)
  ├── use-resize-utils.ts (工具函数)
  ├── use-resize-core.ts ← types + style + utils
  └── use-resize-events.ts ← types + core

resize.vue ← use-resize (全部通过入口导入)
use-resize-watchers.ts ← use-resize + use-resize-events
```
