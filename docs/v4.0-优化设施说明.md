# 微应用框架优化设施说明（v4.0）

> 对标行业主流微前端方案（qiankun / micro-app / wujie）与互联网大厂研发规范，围绕 ydzs-frontend 自研微应用框架（micro-kernel）的架构优化、功能增强、性能提升、体验改善四个维度，本次落地的设施清单。

## 一、本次落地的设施（P2 全部 + 关键 P0/P1）

### 1. Chrome Extension DevTools（P2-1）✅ 完整落地

**路径**：`ydsz-micro/chrome/`

**功能**：
- 浏览器工具栏 Popup 展示内核连接状态、活跃应用、KeepAlive 实例数
- **F12 → Micro Kernel 标签**查看子应用状态列表（状态 / 沙箱类型 / 加载耗时）
- 操作按钮：刷新注册表 / 清缓存 / 健康检查
- 命令下发：子应用「卸载」/「重载」
- 实时生命周期事件日志

**集成方式**：
- `main/src/monitoring/devtools-bridge.ts` —— micro-kernel 生命周期钩子封装
- `main/src/bootstrap.ts` —— 在 `app.mount()` 之后、微前端运行时注册完成后启用
- `comm/effects/micro-kernel/src/kernel.ts` —— 暴露 `healthCheck/refreshRegistry/getAllInstances/getAppInstance` 公开方法

**验证步骤**：
1. `pnpm dev` 启动主应用
2. Chrome → `chrome://extensions` → 加载已解压扩展 → 指向 `chrome/`
3. F12 → 切到「Micro Kernel」标签，刷新页面，观察子应用列表和事件流

详细文档见 [`chrome/README.md`](chrome/README.md)

### 2. 灰度版本分流（P2-2）✅ 完整落地

**路径**：`comm/effects/micro-kernel/src/canary-manager.ts`

**功能**：
- 按用户 ID 哈希分流（FNV-1a，稳定均匀）
- 白名单（`whitelistUserIds`）强制灰度 + 强制标签（`forceTag`）
- 本地缓存（localStorage）+ 远端 Nacos 拉取（自动 60s 刷新）
- 多 Canary 并发（stable + canary-1 + canary-2 百分比累加）

**使用方式**：

```ts
// bootstrap.ts（已集成）
await getCanaryManager().init({ remoteUrl: import.meta.env.VITE_CANARY_CONFIG_URL });

// 在使用 entry 处替换为：
const cm = getCanaryManager();
const { resolved, tag, whitelisted } = cm.resolveVersion('workflow-web', { userId: currentUser.id });
// resolved = { version, tag, entry, percentage, minKernelVersion }
```

**远端配置结构**（对齐 Nacos）：
```json
{
  "enabled": true,
  "whitelistUserIds": ["user-001", "user-002"],
  "forceTag": "canary",
  "apps": [{
    "appName": "workflow-web",
    "stable":   { version: "3.9.0", tag: "stable",   entry: "/main/workflow-web/", percentage: 90 },
    "canaries": [{ version: "4.0.0-rc1", tag: "canary", entry: "/canary/workflow-web/", percentage: 10, minKernelVersion: "4.0.0" }]
  }]
}
```

### 3. Service Worker 资源缓存（P2-3）✅ 完整落地

**路径**：`conf/vite-config/src/plugin-sw.ts`

**策略**：

| 资源类型 | 策略 | 过期时间 |
|---------|------|---------|
| API 请求 | NetworkFirst + BackgroundSync 离线队列 | 5 分钟 |
| 静态资源（js/css/图片） | CacheFirst | 7 天 |
| app-shell | NetworkFirst | 实时 |

**缓存命名**：`v4:{type}-{appName}`，版本切换时自动清理旧缓存。

**使用方式**（在子应用 `vite.config.ts` 中）：
```ts
import { swPlugin } from '@ydsz/vite-config/sw-plugin';
export default defineConfig({
  plugins: [swPlugin({ appName: 'workflow-web' })],
});
```

需安装依赖：`pnpm add -Dw vite-plugin-pwa`

### 4. 全局搜索 + 快捷键中枢（P2-4）✅ 完整落地

**路径**：

- `main/src/components/global-search.vue` —— 搜索面板 UI
- `main/src/hooks/use-global-search.ts` —— 搜索数据注册
- `main/src/hooks/use-global-shortcut.ts` —— 快捷键中枢

**功能**：
- `Cmd/Ctrl + K` 唤起全局搜索面板（通过 App.vue 注册）
- 子应用通过 `registerSearchProvider('app-name', () => items[])` 注册搜索项
- 搜索实时过滤 + 匹配高亮 + 快捷键导航（↑↓ Enter Esc）
- 快捷键中枢支持冲突检测、`enableInInput` 选项、自动清理

**子应用注册示例**：
```ts
import { registerSearchProvider } from '@ydsz/micro-runtime/search';
onMounted(() => registerSearchProvider('workflow-web', () => [
  { id: 'list', title: '项目列表', path: '/YDSZ-proj/opportunities', appName: 'workflow-web' },
  { id: 'new', title: '新建项目', path: '/YDSZ-proj/new', appName: 'workflow-web' },
]));
```

**已注册快捷键**：

| 快捷键 | 作用 | 注册方 |
|--------|------|--------|
| `Cmd+K` | 切换全局搜索面板 | App.vue |

## 三、快速启用清单

### 开发态开箱即用（无需额外配置）

1. `pnpm dev` 启动主应用
2. Chrome 加载 `chrome/` 扩展 → F12 → Micro Kernel 标签
3. `localStorage.setItem('micro-kernel:devtools', '1')` 刷新后自动桥接
4. 按 `Cmd+K` 唤起全局搜索（首次使用无子应用注册项时为空）
5. 拔掉网线 → 顶部红色断网提示；插回 → 绿色恢复提示

### 生产态启用（按需在 `.env.local` 配置）

```env
VITE_CANARY_CONFIG_URL=https://nacos.his.example.com/canary/YDSZ.json
VITE_SENTRY_DSN=https://xxxxx@xxxxx.ingest.sentry.io/xxxxx
```
