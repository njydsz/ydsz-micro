# v4.0 优化设施说明

> 本文对应内核 v4.x 系列引入的优化设施，以代码事实为准（文件路径为证）。
> v4.4.0 增量：预加载指标回环、路由预测冷启动门槛、importmap 版本锁、SSE 生命周期收敛。

## 1. 共享依赖 importmap（v4.0 P1-1）

- 三级共享策略 `core` / `core-ui` / `all`（`conf/vite-config/src/micro-shared-deps.ts`），子应用经 package.json `YDSZ.shareStrategy` 声明
- 自托管模式（默认）：`pnpm sync:shared-deps` 将 ESM 产物下载至 `public/vendor/`，构建期由 importmap 插件读取，消除公网 CDN SPOF
- **版本锁（v4.4.0）**：解析结果写入 `bash/importmap.lock.json`，后续同步按精确版本安装；`--check` 模式（CI）校验跨应用 vendor 产物一致性 + 无悬空引用；`--refresh` 重新解析

## 2. 构建守护

- **bundle-budget 插件**（`conf/vite-config/src/plugins/bundle-budget.ts`）：构建期单 chunk / CSS / 总体积硬阈值，超限失败
- **check:size 脚本**（`bash/check-size.mjs`）：产物级 gzip 预算断言（主应用 512KB / 子应用 384KB），CI 可跑
- **vsh check-bundle**（`bash/vsh/src/check-bundle/`）：产物级共享依赖外置证据检测，防误打包导致双实例
- sourcemap：生产默认 `hidden`；`bash/deploy/nginx.conf` 禁止对外暴露 `.map`（v4.4.0）

## 3. 资源调度（scheduler / task-queue）

- keep-alive + LRU 淘汰 + TTL + 自适应上限（v4.2.1 L4：堆占用 >90% 上限 1 / >70% 上限 3）
- 内存压力检测（v4.4.0）：优先 `performance.measureMemory()`（Chrome 128+ 标准 API），回退已废弃的 `performance.memory`，均不可用时退化为计数启发式（`task-queue.ts` getMemoryUsageMB）
- 可见性自动释放：`visibilitychange` 触发内存压力检查

## 4. 预加载与路由预测

- 四策略：hover / idle / route / frequency（`preload-strategy-helpers.ts`）
- 路由预测：马尔可夫链转移概率（`route-predictor-core.ts`），v4.4.0 增加 `minSampleSize`（默认 3）冷启动门槛——小样本高估的预测一律跳过，自然回退 idle/frequency 基线
- Speculation Rules 预取增强（`speculation-rules.ts`，eager/lazy/never 分档）

## 5. 指标回环（v4.4.0，ADR-006）

- `preload-metrics.ts`：周期采样（默认 120s）+ pagehide 兜底，sendBeacon 上报 preloadCount / consumedCount / wastedCount / hitRate 与马尔可夫转移样本量至 `/api/v1/monitor/preload-metrics`
- 用途：周报对比 route/markov 与 frequency 策略命中率，数据驱动 `routePreload` 开关与门槛调优
- StartOptions：`metricsReporting`（默认开）、`metricsIntervalMs`

## 6. 安全链

- SRI（CSS）+ CSP nonce（`loader.ts`，v4.2.1）：子应用样式完整性校验；JS 侧受 dynamic import 浏览器限制，待 manifest 签名方案（路线图）
- iframe 沙箱 RPC：targetOrigin 收敛 + event.origin 白名单（v4.3.0）
- nginx：strict-dynamic CSP、sourcemap 禁暴露、安全响应头组

## 7. 工程化护栏（v4.4.0 起）

- GitHub Actions：`verify`（lint/stylelint/type-check/check-circular/check-dep/test/check:i18n）+ `contract`（契约漂移）+ `e2e-smoke`（手动触发）
- `check:i18n`：8 应用 × 双语 key 集合静态一致性校验
- `.changeset/`：共享包版本与变更记录流程启用
