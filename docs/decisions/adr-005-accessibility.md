# ADR-005: 可访问性（a11y）基线与验收方式

- **状态**: 部分落地；原 E2E 验收路径已随云顶编码规范 §15.10（禁止测试代码）移除，现行验收以静态门禁 + 人工抽测承接（v4.4.1 修订）
- **关联代码**: ESLint a11y 规则（`conf/lint-configs/eslint-config`）、云顶编码规范第 11 章

> **v4.4.1 修订说明**：本 ADR 最初以 @axe-core/playwright + Playwright E2E 冒烟作为
> a11y 自动化验收路径。2026-08 云顶编码规范 §15.10 落地后，全仓禁止测试代码与
> 测试依赖（含 @axe-core/playwright、@playwright/test），原 E2E 验收路径被废止。
> 本文件保留决策背景，验收方式已按下文更新。

## 背景

README 与云顶编码规范第 11 章均要求语义化 HTML / 键盘可访问性 / ARIA / 颜色对比度，
此前缺少自动化验收手段。

## 决策

1. **静态门禁（现行）**：ESLint a11y 规则随 `pnpm lint` 阻断明显违规（缺失 alt、无效 ARIA、不可聚焦交互元素等）
2. **规范约束**：云顶编码规范第 11 章（语义化 HTML / 键盘可访问性 / ARIA / 颜色对比度）作为评审清单条款执行
3. **人工抽测**：每个新增主链路页面在 PR 评审阶段按第 11 章清单人工过检；复杂键盘路径（焦点管理、模态循环）必须人工验证
4. **修订历史**：v4.4.0 曾以 @axe-core/playwright 建立 `wcag2a`+`wcag21a` `critical=0` 阻断线，该路径已随 §15.10 移除

## 后果

- 正面：a11y 基线仍由 lint 静态阻断 + 规范评审清单双轨承接，无测试依赖负担
- 负面：失去 axe 规则集的运行时扫描能力（布局类违规如对比度、标签关联无法静态检出）；若未来规范放开测试禁令，建议优先恢复 axe 扫描（登录页起步）
