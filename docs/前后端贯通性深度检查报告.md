## 六、最佳实践亮点

1. **Controller ↔ API 文件命名高度一致**：如 `FlowDefinitionController` → `flowDefinition.ts`、`RuleLifecycleController` → `ruleLifecycle.ts`，几乎呈 1:1 映射。

2. **DDD 分层在前端得以保持**：每个子应用独立维护自己的 api/、views/、store/、router/，与后端 `{module}-web` 模块边界严格对齐。

3. **微前端架构 (main/) 分离合理**：
   - main 负责认证、菜单、租户、Dashboard 等**跨切面关注点**
   - 子应用负责各引擎的**核心业务页面**
   - 共享请求客户端 `@ydsz/shared-auth` 统一管理 Token

4. **InternalApiController 模式成熟**：每模块均提供 `InternalXXXApiController` 用于跨服务 Feign/Octo 调用，与前端-facing Controller 清晰分离。

5. **SDK/契约驱动**：大部分子应用/src/api/sdk/ 下有 `openapi.json` + `schema.d.ts`，表明接口通过 OpenAPI 契约驱动，有利于前后端并行开发。
