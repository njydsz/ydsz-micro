# 错误码规范

## 编码规则

错误码统一为 5 位数字字符串，按模块划分区间。

| 区间 | 模块 | 说明 |
|------|------|------|
| `0` | 通用 | 成功 |
| `1xxxx` | 通用 | 参数校验、格式错误 |
| `20000-20099` | 网关 | 路由、限流、熔断错误 |
| `20100-20199` | 系统引擎 | 配置/字典/租户错误 |
| `20200-20299` | 身份引擎 | 认证/MFA/权限错误 |
| `20300-20399` | 消息引擎 | 渠道配置/发送错误 |
| `20400-20499` | 文件引擎 | 上传/下载/安全扫描错误 |
| `20500-20599` | 流程引擎 | 流程定义/实例错误 |
| `20600-20699` | 任务引擎 | 调度/分片/执行错误 |
| `20700-20799` | 规则引擎 | 表达式编译/沙箱错误 |
| `20800-20899` | 智能引擎 | LLM/Agent/RAG 错误 |

## 通用错误码

| 错误码 | 说明 |
|--------|------|
| `10001` | 参数校验失败 |
| `10002` | 参数缺失 |
| `10003` | 数据格式错误 |
| `40001` | 未认证（Token 无效或过期） |
| `40003` | 权限不足 |
| `50001` | 服务内部错误 |

## 权限错误码

| 错误码 | 说明 |
|--------|------|
| `40101` | 用户名或密码错误 |
| `40102` | 验证码错误 |
| `40103` | MFA 验证失败 |
| `40104` | Token 已过期 |
| `40105` | 账号已锁定 |

## 生成方式

错误码通过 `pnpm gen:error-codes` 从各引擎的 ErrorCode 枚举自动扫描生成，集中输出到 `docs/error-codes.generated.md`。

> 注意：每个引擎的 ErrorCode 枚举必须使用 `@ErrorCodeDesc` 注解描述错误含义，方能被扫描器识别并纳入统一文档。
