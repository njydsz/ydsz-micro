# YdBadge

状态标签：按语义 variant 取 cva 变体类名，用于标注状态、计数与分类。 刻意不提供 size 维度 —— 标签需要跟随所在文本的行高，

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\badge\YdBadge.vue`

## Props

| 属性      | 类型                       | 必填 | 默认值 | 说明 |
| --------- | -------------------------- | ---- | ------ | ---- |
| `class`   | `ClassValue`               | 否   | -      | -    |
| `variant` | `BadgeVariants['variant']` | 否   | -      | -    |
