# YdCardHeader

卡片头部区：容纳标题与描述的纵向排布容器。 用 flex 纵向布局加固定间距，让标题与描述的间距不依赖具体元素的 margin，

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\card\YdCardHeader.vue`

## Props

| 属性    | 类型         | 必填 | 默认值 | 说明 |
| ------- | ------------ | ---- | ------ | ---- |
| `class` | `ClassValue` | 否   | -      | -    |
