# YdCol

栅格列组件 —— 与 YdRow 配对使用。 API 对齐 Element Plus ElCol：

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\layout\YdCol.vue`

## Props

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `span` | `number` | 否 | - | 栅格占位格数（1-24），0 时隐藏 |
| `offset` | `number` | 否 | - | 栅格左侧的间隔格数 |
| `push` | `number` | 否 | - | 栅格向右移动的格数 |
| `pull` | `number` | 否 | - | 栅格向左移动的格数 |
| `xs` | `number` | 否 | - | 响应式 xs (<768px) 列数 |
| `sm` | `number` | 否 | - | 响应式 sm (≥768px) 列数 |
| `md` | `number` | 否 | - | 响应式 md (≥992px) 列数 |
| `lg` | `number` | 否 | - | 响应式 lg (≥1200px) 列数 |
| `xl` | `number` | 否 | - | 响应式 xl (≥1600px) 列数 |
| `xxl` | `number` | 否 | - | 响应式 xxl (≥1920px) 列数 |
| `class` | `HTMLAttributes['class']` | 否 | - | 自定义 class |
