# YdButtonGroup

按钮组容器：为一组按钮提供统一的间距与圆角衔接。 相邻按钮共享边框（除首尾外去掉内侧圆角与重复边线），使一组操作在视觉上连成整体；

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\button\YdButtonGroup.vue`

## Props

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `border` | `boolean` | 否 | - | - |
| `gap` | `number` | 否 | - | - |
| `size` | `'large' | 'middle' | 'small'` | 否 | - | - |
