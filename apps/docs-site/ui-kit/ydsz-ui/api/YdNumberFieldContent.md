# YdNumberFieldContent

数字输入框的定位容器：为绝对定位的增减按钮提供 relative 参照系，并按按钮存在与否调整输入框内边距。 内边距用 has-[[data-slot=decrement]] / has-[[data-slot=increment]] 选择器判定，

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\number-field\YdNumberFieldContent.vue`

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `class` | `any` | 否 | - | - |
