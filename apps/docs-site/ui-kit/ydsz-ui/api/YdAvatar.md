# YdAvatar

头像容器：按 shape /
size 两个维度从 cva 变体中取类名，默认圆形小号。 尺寸与圆角全部由 avatarVariant 统一产出，外部若要覆盖必须走 cn()，

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\avatar\YdAvatar.vue`

## Props

| 属性    | 类型                      | 必填 | 默认值 | 说明 |
| ------- | ------------------------- | ---- | ------ | ---- |
| `class` | `ClassValue`              | 否   | -      | -    |
| `shape` | `AvatarVariants['shape']` | 否   | -      | -    |
| `size`  | `AvatarVariants['size']`  | 否   | -      | -    |
