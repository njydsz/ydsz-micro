# YdToggleGroupItem

切换按钮组中的一项：从 toggleGroup 上下文取 variant / size，自身 props 优先。 变体取值先从 inject 的上下文中取、再与本地 props 合并，

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\toggle-group\YdToggleGroupItem.vue`

## Props

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `class` | `ClassValue` | 否 | - | - |
| `size` | `ToggleGroupVariants['size']` | 否 | - | - |
| `variant` | `ToggleGroupVariants['variant']` | 否 | - | - |
