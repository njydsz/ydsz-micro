# YdDescriptionsItem

描述列表字段项：承载「标签 — 文本」一对信息，由 YdDescriptions 容器编排网格位置。 与 EP
ElDescriptionsItem 的契约对齐：

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\descriptions\YdDescriptionsItem.vue`

## Props

| 属性           | 类型         | 必填 | 默认值 | 说明                 |
| -------------- | ------------ | ---- | ------ | -------------------- |
| `class`        | `ClassValue` | 否   | -      | -                    |
| `label`        | `string`     | 否   | -      | 标签文本             |
| `span`         | `number`     | 否   | -      | 横向跨越列数，默认 1 |
| `labelClass`   | `ClassValue` | 否   | -      | 标签列自定义类名     |
| `contentClass` | `ClassValue` | 否   | -      | 内容列自定义类名     |
