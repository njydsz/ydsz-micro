# YdIcon

通用图标渲染器：按传入值的类型自动选择渲染方式。 同一组件兼容四种输入——Vue 组件直接渲染、http(s) 链接渲染为 img、

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\icon\YdIcon.vue`

## Props

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `fallback` | `boolean` | 否 | - | - |
| `icon` | `Component | Function | string` | 否 | - | - |
