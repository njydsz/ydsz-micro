# YdExpandableArrow

可展开箭头：点击切换展开态并旋转指示箭头，用于展开/收起区域。 用 div +
role="button" 而非 button 元素，是为了能自由承载任意行内内容而不

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\expandable-arrow\YdExpandableArrow.vue`

## Props

| 属性    | 类型     | 必填 | 默认值 | 说明 |
| ------- | -------- | ---- | ------ | ---- |
| `class` | `string` | 否   | -      | -    |
