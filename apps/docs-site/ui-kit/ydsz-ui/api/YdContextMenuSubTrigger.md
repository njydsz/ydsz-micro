# YdContextMenuSubTrigger

子菜单触发器：渲染带展开指示的菜单项，悬停或右方向键展开子菜单。 展开与收起的延迟由 radix 处理，避免鼠标斜向移动时误收起子菜单。

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\context-menu\YdContextMenuSubTrigger.vue`

## Props

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `class` | `any` | 否 | - | - |
| `inset` | `boolean` | 否 | - | - |
