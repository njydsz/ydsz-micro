# YdTimelinePro

时间轴 Pro——带 alternate / ghost 增强模式。 alternate 模式下，内容项自动在时间轴左右交替排列。

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\timeline\YdTimelinePro.vue`

## Props

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `class` | `any` | 否 | - | 自定义类名 |
| `pending` | `string` | 否 | - | pending 节点文案 |
| `pendingDot` | `boolean` | 否 | - | 是否显示 pending 脉冲动画 |
| `reverse` | `boolean` | 否 | - | 是否反转排序 |
| `alternate` | `boolean` | 否 | - | 交替模式：内容项在时间轴两侧交替显示 |
| `ghost` | `boolean` | 否 | - | 幽灵模式：更轻量的视觉风格 |
