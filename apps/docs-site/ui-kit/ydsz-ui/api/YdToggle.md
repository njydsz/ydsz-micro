# YdToggle

切换按钮：在 radix YdToggle 之上套用 toggleVariants 的 variant / size 变体。 size 与 variant 要从 props 中单独摘出再转发，

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\toggle\YdToggle.vue`

## Props

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `class` | `ClassValue` | 否 | - | - |
| `size` | `ToggleVariants['size']` | 否 | - | - |
| `variant` | `ToggleVariants['variant']` | 否 | - | - |
