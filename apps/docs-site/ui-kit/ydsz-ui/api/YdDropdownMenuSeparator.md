# YdDropdownMenuSeparator

下拉菜单分隔线：在菜单项之间绘制视觉分组线。 纯装饰元素，对辅助技术不可见；语义分组请用 YdDropdownMenuGroup 表达。

> 源文件：`comm\@core\ui-kit\ydsz-ui\src\components\dropdown-menu\YdDropdownMenuSeparator.vue`

|------|------|------|--------|------|
